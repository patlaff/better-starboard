# Privacy Policy for Better-Starboard

*Effective Date*: 2/12/2025

*Last Updated*: 2/12/2025

Better-Starboard ("the App") is a Discord bot that enables users to create a customizable starboard system within their Discord servers based on any number of reactions. This Privacy Policy outlines how we collect, use, and protect information related to the App’s functionality.

## 1. Information We Collect
Better-Starboard collects and processes the following types of data:
- **Server Configuration Data**: This includes guild IDs, channel IDs, and message IDs for messages posted to the starboard.
- **Reaction Data**: The App listens for reactions on messages within included channels but does not store reaction data after processing.
- **Starboard Post Information**: When a message meets the reaction threshold, the App posts the message to the starboard channel, including a link to the original post, the author’s username, and aggregated reaction information.
- **Message Data**: Messages are temporarily cached by the App when a post is pinned to the starboard. This data is not retained in any way after this process is complete.

### Data We Do Not Collect:
- Message content is never stored.
- User messages and private communications are not accessed or retained.

## 2. How We Use the Information
The collected data is used solely to facilitate the core functionality of the App:

- Determining whether a message meets the reaction threshold for posting to the starboard.
- Storing configuration settings for each server where the App is used.
- Displaying aggregated reaction information within the starboard post.

## 3. Data Storage and Security

- All stored data is maintained in an SQLite database hosted on AWS.
- No personally identifiable information (PII) is collected or stored.
- Reasonable security measures are in place to protect stored data from unauthorized access or misuse.

## 4. Data Sharing and Disclosure

Better-Starboard does not share, sell, or disclose collected data to third parties, except:

- When required by law or legal process.
- If necessary to prevent fraud, security threats, or technical issues.

## 5. User Control and Data Removal

- Server administrators can remove the bot from their server at any time, preventing further data collection.
- Users can request the deletion of stored configuration data by contacting [laff.discord.bots@gmail.com](laff.discord.bots@gmail.com).

## 6. Changes to this Privacy Policy
We may update this Privacy Policy periodically. Users will be notified of significant changes through our official communication channels.

## 7. Contact Information
If you have any questions or concerns regarding this Privacy Policy, please contact us at [laff.discord.bots@gmail.com](laff.discord.bots@gmail.com).
